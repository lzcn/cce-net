# CCE-Net

Official implementation of **CCE-Net: Learning Fashion Compatibility with Context Conditioning Embedding** for fashion outfit compatibility modeling.

This repository has been refactored with the assistance of LLMs.

## Requirements

See `requirements.txt`. Tested with PyTorch 2.6.0 (CUDA 11.8) and PyTorch Geometric 2.6.1.

```bash
conda create -n cce-net python=3.10 -y
conda activate cce-net
pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu118
pip install -r requirements.txt
```

## Data

Download the preprocessed datasets (item features and outfit splits) from Hugging Face:

```bash
git clone https://huggingface.co/datasets/lzcn/outfit-datasets outfits-hf
```

Place the folder next to this repository so that `--data-dir ../outfits-hf` resolves.
Supported splits include:

- `maryland-polyvore/original`
- `polyvore-outfits/disjoint`, `polyvore-outfits/nondisjoint`
- `polyvore-u/original/tuples_519`

## Training

```bash
python train_cce_infonce.py \
    --data-dir ../outfits-hf \
    --data-set maryland-polyvore/original \
    --norm --feat-norm --neg-type-aware --trans-layer \
    --tau 0.10 --base-model GATConv --batch-size 128 --lr 0.1 \
    --num-layers 2 --neg-ratio 1 --num-neg 8 \
    --log-dir runs/maryland-polyvore-infonce
```

Triplet loss variant:

```bash
python train_cce_triplet.py \
    --data-dir ../outfits-hf \
    --data-set maryland-polyvore/original \
    --norm --feat-norm --neg-type-aware --trans-layer \
    --tau 0.10 --num-neg 1 \
    --log-dir runs/maryland-polyvore-triplet
```

Equivalent shell scripts are provided under `scripts/`.

## Evaluation

Evaluate a trained checkpoint with random-mixed negatives (`all`) or negatives generated by replacing `k` items:

```bash
python train_cce_infonce.py \
    --data-dir ../outfits-hf \
    --data-set maryland-polyvore/original \
    --test --load-trained runs/maryland-polyvore-infonce/checkpoints/net_best.pt
```

Add `--neg-mode RandomReplace --num-replace k` for the replacement setting.

## Main Options

| Option | Description |
| --- | --- |
| `--base-model` | context encoder backbone: `GATConv` (default), `GCNConv`, `GraphConv`, `PointConv` |
| `--without-context` | disable the context branch |
| `--trans-layer` | add MLPs to the general embedding branch |
| `--full-graph` | symmetric context injection between all nodes |
| `--fuse-score --fuse-isomeric` | hybrid variant fusing both branches with `--fuse-beta B` |
| `--norm` / `--feat-norm` | L2-normalize output / input features |
| `--neg-mode` | negative generation: `RandomMix`, `RandomReplace`, `Fix` |
